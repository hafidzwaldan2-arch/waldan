# 🎨 Digitama — Jasa Website Sederhana untuk UMKM

Digitama adalah jasa pembuatan website landing page profesional untuk UMKM dengan harga terjangkau dan proses cepat (2-4 hari kerja).

## 🚀 Fitur

- ✅ **Responsive Design** — Tampil rapi di HP, tablet, dan desktop
- ✅ **SEO-Friendly** — Mudah ditemukan di search engine
- ✅ **Animasi Modern** — User experience yang menyenangkan
- ✅ **Portfolio Dinamis** — Showcase hasil kerja dengan mudah
- ✅ **Form Konsultasi** — Interaktif dan terintegrasi WhatsApp
- ✅ **Gratis 2x Revisi** — Sesuaikan sesuai keinginan

## 📦 Paket Harga

| Paket | Harga | Fitur |
|-------|-------|-------|
| **Basic** | Rp 75.000 | 1 halaman, profil & kontak |
| **Standar** | Rp 125.000 | Basic + galeri produk + peta lokasi |
| **Premium** | Rp 175.000 | Standar + tema warna custom + 1 halaman tambahan |

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Design**: Mobile-first, Grid Layout
- **Font**: Space Grotesk (headings), Inter (body)
- **Colors**: Navy #16324F, Teal #1E7F72, Gold #C9A24B
